# 🌤️ Weather App

A responsive weather forecast app built with **vanilla JavaScript** and **Bootstrap**. It detects your location automatically, or you can search any city, and it shows current conditions plus a 3-day forecast.

## ✨ Features

- **Auto-location**: uses the browser Geolocation API to show local weather on load.
- **City search**: look up the weather for any city worldwide.
- **3-day forecast**: temperature, conditions and icons for today and the next two days.
- **Async data fetching** with `fetch` and `async/await`, with error handling.
- **Responsive layout** built with the Bootstrap 5 grid.

## 🧱 Tech Stack

- HTML5, CSS3, Bootstrap 5, Font Awesome
- Vanilla JavaScript (Fetch API, Geolocation API, DOM manipulation)
- [WeatherAPI.com](https://www.weatherapi.com/) forecast endpoint

## 🚀 Run Locally

```bash
git clone https://github.com/ammar-gomaa/Weather-App.git
cd Weather-App
# open index.html in your browser
```

> Get a free API key from [weatherapi.com](https://www.weatherapi.com/) and set it at the top of `javascript/script.js`.
